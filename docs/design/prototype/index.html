Every lesson goes in the same order.

So you always know what is being asked of you.

  1. Discover

    One idea, in a few sentences.

  2. Worked example

    Code you read line by line, with the output beside it.

  3. Predict

    Guess what it prints before it runs. Guess wrong and you get the reason.

  4. Try it

    Change the example and see what moves.

  5. Challenge

    Write the program yourself. Hidden test cases catch copied answers.

When it breaks, you are told why.

The page marks the line, says what Python couldn't do, and often guesses the name you meant. Python's own message is a click away.

Stuck? Hints come in steps: a nudge, a bigger hint, then the approach. There is no button that hands you the answer.
