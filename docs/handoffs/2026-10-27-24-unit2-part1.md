## 3. How it works

**The story.** The adventure gains a score and riddles with number answers. Lesson 1 shares a chest of coins between friends; lesson 2 averages two riddle scores (one can be negative); lesson 3 asks the player for a score and a riddle's points and prints the score if the riddle is solved and if it is missed.

**Each lesson** has unit 1's five cards: discover, a worked example (with comments naming each step), predict, "Try it", and the challenge. Predict-then-run: card 3 asks for a prediction about the example, and card 4 asks the learner to predict, then run and compare. Worked examples use a different context from the challenge (a gem score, a walk to the market, a bridge toll).

**Support fades:** lessons 1 and 2 give the two `int(input(...))` lines in the starter ("lesson 3 explains how"); lesson 3's starter is three comments only, and the learner writes the conversions.

**Checks** (ENG-03, unchanged): each challenge has 5 cases, 3 visible and 2 hidden, with the 3-second limit. The program prints **just the numbers**, so the check measures the arithmetic, not the wording. Edge cases taught: an exact share (leftover 0), fewer coins than friends (share 0), `/` giving a float even for a whole answer (`7.0`), a negative average and `int()` cutting toward zero (`-0.5` → `0`), a score going below zero, and an **empty** reply. Hidden cases use other numbers, so hard-coded output fails.

**Rules and messages.** Browser checks name a wrong-output result `<lesson>.case.<case id>` (handoff 22), for example `py.arithmetic.case.fewer`. Its message is the judge's sentence, built from the case's description: "For 3 coins and 5 friends, line 1 should be "0", but your program printed "1"." Hidden cases are named only by their description ("a big chest (a hidden test case)"). Browser-check challenges cannot have content `messages` (the API refuses them), so the per-case teaching words are in **tagged hints**, offered first when that case fails.

**The end of what is released.** After lesson 3, the lesson menu shows 3 of 3, the card's button is "Revisit this quest" (there is no next lesson), and the box under the card now says: **"You finished every lesson released so far. That is all of Numbers and decisions for now. See the course for what comes next."** It used to say "Unit complete. Every lesson in … is done", which is not true while unit 2 has three of its six lessons. Unit 1's own ending is unchanged.
