## Appendix. Every card, hint and check case, word for word

### A.1 `py.accumulate`: Keep the score

Concept: Loops · running totals and counters. Description: Add up the points from every round of the riddle keeper's game, count the empty rounds, and find the average. Badge: **Tally keeper** (`py.badge.tally-keeper`, practice).

| Card | Text |
| --- | --- |
| 1. Discover: Build up an answer, one turn at a time | A running total starts at 0 before the loop. Inside the loop, total = total + coins adds this turn's number to what is already there. When the loop ends, total holds the sum of them all.<br><br>A counter works the same way, but adds 1 each time something happens, often inside an if. The start line goes above the loop, so it runs once: inside the loop it would wipe the total every turn. For an average, divide the total by how many numbers there were, after the loop. |
| 2. Worked example | `# Three chests: add up the coins, then find the average` / `chests = 3` / `total = 0` / `for chest in range(chests):` / `    coins = int(input("Coins in this chest? "))` / `    total = total + coins` / `print(total)` / `print(total / chests)`<br>Replies: Reply 1: '4', Reply 2: '0', Reply 3: '8'. Output: `12` / `4.0`<br>total starts at 0 and grows: 4, then 4 again, then 12. The two print lines are below the loop, not indented, so they run once, after the last chest. Dividing with / always gives a float, so the average shows as 4.0. |
| 3. Predict | Suppose total = 0 moves inside the loop, as the first line of its block. With the same replies, what would print(total) show?<br>Options: **8** (answer); 12; 0<br>Why: total goes back to 0 at the start of every turn, so each chest forgets the ones before it. Only the last chest's 8 is left when the loop ends. |
| 4. Try it | Predict, then run: move total = 0 inside the loop, as the first line of its block, and check your prediction. Put it back above the loop. Then add a counter for empty chests: start it above the loop, add 1 inside an if, and print it at the end. |
| 5. Challenge | The riddle keeper's game now has rounds. Ask how many rounds were played (always at least 1), then ask for the points from each round. Print three lines: the total points, how many rounds scored 0, and the average points per round, using /. Print just the numbers.<br>Starter: `# Ask for the rounds, then the points from each round` |

| Hint | Text |
| --- | --- |
| A nudge | You need two things that build up as the loop runs, and both start at 0 above the loop: one for the points, and one for the rounds that scored 0. |
| A bigger hint | A for loop over range() runs once per round. Ask for that round's points inside it. The three print lines go after the loop, with no indent. |
| The approach | A pattern with other names: start with distance = 0, and inside the loop use distance = distance + miles. Your loop also needs a counter, and an if to decide when it goes up. |
| About `TypeError` | A reply from input() is text. Turn it into a number with int(...) before you add it up or use it in range(). |
| About `NameError` | Give each name a value before the loop uses it, and spell it the same way every time. |
| About `IndentationError` | The lines that repeat start with four spaces. A line inside an if inside the loop starts with eight. |
| About `EOFError` | Your loop asked for more points than there were rounds. range(rounds) already runs exactly once per round. |
| About `ZeroDivisionError` | The average divides by the number of rounds played, and that is always at least 1. Check which number comes after the /. |
| About `py.accumulate.case.one-round` | With one round of 10 points, the lines are 10, 0 and 10.0. A total or a counter that starts above 0 is already wrong here, and // gives 10 where / gives 10.0. |
| About `py.accumulate.case.three-rounds` | With rounds of 10, 0 and 5, the lines are 15, 1 and 5.0. If your total says 5, it goes back to 0 on every turn: its start line belongs above the loop. |
| About `py.accumulate.case.no-points` | With two rounds of 0, the lines are 0, 2 and 0.0. Every round that scores 0 counts, even when nothing has been scored yet. |
| About `py.accumulate.case.many-rounds` | Check a longer game: use the number of rounds in range() and in the average, and / rather than //, which throws away the part after the point. |
| About `py.accumulate.case.more-empty` | Check a game with more than one empty round: the counter goes up every time a round scores 0. |
| Similar example | `gold = 1` / `for day in range(3):` / `    gold = gold * 2` / `print(gold)`<br>Another answer that builds up: the gold doubles each day, giving 8 after three days. It starts at 1, because doubling 0 would stay 0. Your challenge adds up every round and counts the empty ones instead. |
| Other way, after passing | `rounds = int(input("Rounds? "))` / `total = 0` / `empty = 0` / `count = 0` / `while count < rounds:` / `    points = int(input("Points? "))` / `    total = total + points` / `    if points == 0:` / `        empty = empty + 1` / `    count = count + 1` / `print(total)` / `print(empty)` / `print(total / rounds)`<br>The same totals with a while loop, which needs its own count of the rounds so far. for and range() do that counting for you. |
| Other way, after passing | `rounds = int(input("Rounds? "))` / `total = 0` / `scored = 0` / `for game in range(rounds):` / `    points = int(input("Points? "))` / `    total += points` / `    if points > 0:` / `        scored += 1` / `print(total)` / `print(rounds - scored)` / `print(total / rounds)`<br>Count the rounds that scored instead, and take them away from all the rounds. += is a short way to write total = total + points. |

### A.2 `py.nested-loops`: Rooms on the map

Concept: Loops · a loop inside a loop. Description: Walk the riddle keeper's map row by row, count the coins in each room, and add them all up. Badge: **Map reader** (`py.badge.map-reader`, practice).

| Card | Text |
| --- | --- |
| 1. Discover: Put a loop inside a loop | A loop's block can hold another loop. The inner loop runs all the way through, every time the outer loop goes round once. So an outer loop of 2 turns and an inner loop of 3 turns runs the inner block 6 times.<br><br>The outer loop's line starts at the left, the inner loop's line has four spaces, and the inner block has eight. for and range() start the inner loop again by themselves. With while, the inner counter has to be set back to its start inside the outer loop, or the inner loop only runs the first time. |
| 2. Worked example | `# Number the seats: two rows of three` / `for row in range(1, 3):` / `    for seat in range(1, 4):` / `        print(row * 10 + seat)`<br>Output: `11` / `12` / `13` / `21` / `22` / `23`<br>row starts at 1, and seat runs through 1, 2 and 3. Then row becomes 2, and seat starts again from 1. Multiplying by 10 is just a way to show both numbers at once: 23 is row 2, seat 3. |
| 3. Predict | If the two for lines swapped places, so that seat is the outer loop and row the inner one, what would the first three lines print?<br>Options: **11, 21 and 12** (answer); 11, 12 and 13; 11, 21 and 31<br>Why: The inner loop finishes first. seat stays at 1 while row runs through 1 and 2, giving 11 and 21. Then seat becomes 2 and row starts again, giving 12. |
| 4. Try it | Predict, then run: swap the two for lines, with row and seat keeping their ranges. Put them back. Then change range(1, 3) to range(1, 4) and predict how many lines print before you run. |
| 5. Challenge | The riddle keeper's map is a grid of rooms. Rows and columns are counted from 1, and a room holds its row number times its column number in coins, so row 2, column 3 holds 6. Ask for the number of rows, then the number of columns. Going through the rows in order, and left to right along each row, print the coins in every room, one per line. On the last line, print the total coins. Print just the numbers.<br>Starter: `# Ask for the rows and the columns, then walk the map` |

| Hint | Text |
| --- | --- |
| A nudge | One for loop goes through the rows. Inside its block, another for loop goes through the columns of that row. |
| A bigger hint | Rows and columns count from 1, and range() stops before its second number. The total starts at 0 above both loops, and prints below both of them. |
| The approach | A pattern with other names: for shelf in range(1, shelves + 1): holds for book in range(1, books + 1): one step further in. The rooms need your own names, your own sum, and a total. |
| About `TypeError` | range() needs whole numbers. Turn each reply into a number with int(...) before you use it. |
| About `NameError` | Use one name for the rows and one for the columns, and give each a value with input() before the loops. |
| About `IndentationError` | Each loop's block goes four spaces further in than its for line: four for the inner for line, and eight for the lines inside it. |
| About `EOFError` | This program needs only two replies, the rows and the columns. Ask for them once, above the loops. |
| About `py.nested-loops.case.wide` | With 2 rows of 3 columns, the coins go 1, 2, 3, then 2, 4, 6, and the total is 18. If you see 1, 2, 2, 4, 3, 6, the two loops are the wrong way round. If only the first row printed, the inner counter did not start again. |
| About `py.nested-loops.case.tall` | With 3 rows of 2 columns, the coins go 1, 2, then 2, 4, then 3, 6. Use the replies in your range() calls, not numbers typed into the code. |
| About `py.nested-loops.case.single` | A map of one room holds 1 coin, so the lines are 1 and then the total, 1. The total line is always printed. |
| About `py.nested-loops.case.more-rows` | Check a map with more rows than the examples: the outer range() has to follow the rows reply. |
| About `py.nested-loops.case.more-columns` | Check a map with more columns than the examples: the inner range() has to follow the columns reply. |
| Similar example | `for hour in range(1, 3):` / `    for minute in range(0, 60, 30):` / `        print(hour * 100 + minute)`<br>A clock that strikes every half hour shows 100, 130, 200 and 230: for each hour, the minutes start again from 0. Your challenge goes through rows and columns, counts from 1, and adds everything up. |
| Other way, after passing | `rows = int(input("Rows? "))` / `columns = int(input("Columns? "))` / `total = 0` / `row = 1` / `while row <= rows:` / `    column = 1` / `    while column <= columns:` / `        print(row * column)` / `        total = total + row * column` / `        column = column + 1` / `    row = row + 1` / `print(total)`<br>The same walk with while loops.
