## 11. Removing the worktree safely

Everything in `/Users/DEV/Projects/python-academy-readme` is committed and pushed. Only ignored files (`node_modules`, `.next`, caches) and the untracked `frontend/AGENTS.md`, which Next.js creates when it builds, are left. Because that file is untracked, `git worktree remove` refuses unless it is gone first. From the **main** folder:

```sh
cd /Users/DEV/Projects/python-academy
git -C ../python-academy-readme status --short   # shows only ?? frontend/AGENTS.md
rm ../python-academy-readme/frontend/AGENTS.md   # generated by Next.js, not part of the project
git worktree remove ../python-academy-readme     # deletes only that folder; refuses if anything else is uncommitted
git worktree prune
```

After this PR is merged, `git branch -d docs/readme` deletes the local branch; `-d` refuses if it is not merged. Don't delete the folder in the Finder or with `rm -rf`: Git would keep a stale record of it (`git worktree prune` fixes that). The UI-05 worktree (`../python-academy-ui05`) and the FB-04 worktree (`../python-academy-fb04`) are removed the same way, after `rm`-ing their own `frontend/AGENTS.md` if `git status` shows one.
